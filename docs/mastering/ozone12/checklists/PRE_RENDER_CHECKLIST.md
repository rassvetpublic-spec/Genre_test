# Pre-render Checklist

- [ ] Base audio = source WAV; MP3 только reference/codec.
- [ ] Current winner XML загружен и не invalid.
- [ ] PluginVer/Build проверены; ElementChain decoded.
- [ ] Меняется только active module или declared control pass.
- [ ] Prior accepted module blocks и unknown data сохранены.
- [ ] Probe явно помечен и не считается final автоматически.
- [ ] Stereoize / Soft Clip / Low Level Boost Off без отдельного теста.
- [ ] Для drum-forward pass Transient сохранён, DynEQ low bands обоснованы.
- [ ] Normalize Off; render 48 kHz WAV из source.
