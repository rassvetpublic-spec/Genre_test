Genre_test 0.4.0 Portable — инструкция
=====================================

ЧТО ЭТО
-------
Genre_test — локальный анализатор музыки для Windows: MAEST Discogs519 + AudioSet AST, Normal/SUNO/Distributor вывод, история и Validation.

БЫСТРЫЙ СТАРТ
-------------
1. Распакуйте Genre_test_0.4.0_portable.zip в обычную локальную папку.
2. Рекомендуется короткий ASCII-путь, например:

   C:\Genre_test_0.4.0_portable

Фиксированный путь больше НЕ обязателен.
3. Не запускайте программу прямо внутри ZIP.
4. Запускайте только:

   Genre_test_START.cmd

5. На первом запуске нужен интернет.

ЧТО ДЕЛАЕТ ПЕРВЫЙ ЗАПУСК
------------------------
Portable использует штатный Windows PowerShell 5.1. PowerShell 7 заранее не нужен.

Launcher автоматически проверяет/подготавливает:
- WinGet / App Installer и официальный repair через Microsoft.WinGet.Client при необходимости;
- Microsoft Visual C++ 2015–2022 x64 Runtime;
- Python 3.11 / 3.12 / 3.13 x64;
- если совместимого Python нет — устанавливает Python 3.12 x64;
- отдельный .venv внутри папки Genre_test;
- PyTorch 2.12.1;
- для NVIDIA — CUDA 13.0 / cu130;
- для Blackwell проверяет нативную архитектуру активной GPU, включая sm_120;
- на компьютере без NVIDIA устанавливает CPU PyTorch;
- FFmpeg;
- зависимости Genre_test;
- genre-test --version;
- genre-test doctor;
- после успешной проверки открывает GUI.

PYTHON 3.13
-----------
Если на компьютере уже установлен Python 3.13 x64, он используется штатно. Отдельный Python 3.12 при этом не устанавливается. Поддерживаются 3.11, 3.12 и 3.13 x64.

PYTORCH / NVIDIA / CPU
----------------------
PyTorch нужен и при работе на CPU, потому что MAEST и AudioSet AST работают через PyTorch.

Если NVIDIA есть, bootstrap устанавливает/проверяет PyTorch 2.12.1 + CUDA 13.0. NVIDIA определяется не только через nvidia-smi, но и через Windows PnP/CIM. Если NVIDIA физически присутствует, но CUDA 13 / native architecture не работают, bootstrap завершится ошибкой, а не скроет проблему CPU fallback-ом.

На настоящем CPU-only компьютере CPU PyTorch является штатным режимом; Runtime Health показывает CUDA: N/A и GPU: N/A.

Повторно многогигабайтный Torch не скачивается, если существующий .venv уже совместим. Обычные pip/Hugging Face cache используются повторно, но чужой project .venv напрямую не подключается.

МОДЕЛИ
------
При первом анализе могут скачаться pinned-модели MAEST Discogs519 и AudioSet AST с Hugging Face. Для этих публичных моделей токен не обязателен. Весов моделей в ZIP нет.

ТЁМНАЯ ТЕМА И GUI
-----------------
По умолчанию используется тёмная тема; сверху можно переключить Тёмная / Светлая без перезапуска.

Вкладки:
- Анализ — обычный анализ файлов/папок;
- Validation — повторный анализ и проверка drift/сходимости;
- Проверка — сравнение уже сохранённых сборок без повторного анализа аудио.

ЛОГИ
----

   .genre_test\bootstrap.log

   .genre_test\torch_import_diagnostic.txt

Основной лог:

   .genre_test\logs\genre_test.log

ПОВТОРНЫЙ ЗАПУСК
----------------
Снова запускайте Genre_test_START.cmd. Совместимые Python, .venv, PyTorch и FFmpeg переиспользуются после проверки.

После создания .venv не рекомендуется переносить всю распакованную папку в другое место: сначала выберите конечный каталог, затем выполняйте первый запуск.

СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
- Windows 10/11 x64;
- Windows PowerShell 5.1;
- интернет на первом setup/скачивании моделей;
- несколько ГБ свободного места для Python/PyTorch/моделей;
- NVIDIA не обязательна.
