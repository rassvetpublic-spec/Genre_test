Genre_test 0.3.6 Portable — инструкция
=====================================

ЧТО ЭТО
-------
Genre_test — локальный анализатор музыкального жанра для Windows.
Этот portable prerelease собран так, чтобы на другом компьютере не требовалось вручную настраивать Python, виртуальное окружение, PyTorch или FFmpeg.

БЫСТРЫЙ СТАРТ
-------------
1. Полностью распакуйте ZIP в обычную папку, например:
   D:\Genre_test

2. На первом запуске компьютер должен быть подключён к интернету.

3. Дважды щёлкните:
   Genre_test_START.cmd

4. Ничего дополнительно вводить не нужно. Скрипт автоматически:
   - проверит Windows x64
   - найдёт подходящий Python 3.11/3.12 x64
   - при отсутствии установит Python 3.12 через winget
   - создаст локальное окружение .venv
   - определит наличие NVIDIA GPU
   - установит PyTorch CUDA 12.8 для NVIDIA либо CPU-версию PyTorch
   - найдёт FFmpeg
   - при отсутствии установит Gyan.FFmpeg через winget
   - установит зависимости Genre_test
   - выполнит Runtime Health
   - выполнит genre-test --version
   - выполнит genre-test doctor
   - после успешной диагностики автоматически запустит GUI

5. При первом анализе аудио программа может скачать модель MAEST с Hugging Face. Это нормально. Модель затем хранится в локальном кэше проекта и повторно обычно не скачивается.

ПОВТОРНЫЙ ЗАПУСК
----------------
В дальнейшем снова запускайте только:

   Genre_test_START.cmd

Уже установленный Python, .venv, PyTorch и FFmpeg будут переиспользованы после проверки, поэтому повторный запуск заметно быстрее.

СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
- Windows 10 или Windows 11 x64
- интернет на первом запуске
- желательно не менее 8 ГБ свободного места перед первой установкой
- для автоматической установки Python/FFmpeg нужен Windows Package Manager (winget / App Installer)

NVIDIA не обязательна. Без NVIDIA программа автоматически использует CPU PyTorch, но анализ будет медленнее.

ЕСЛИ НЕТ WINGET
---------------
Если Windows Package Manager отсутствует, скрипт попытается открыть страницу App Installer в Microsoft Store и остановится с понятным сообщением.
После установки/обновления App Installer снова запустите:

   Genre_test_START.cmd

ДИАГНОСТИКА
-----------
Лог первоначальной настройки:
   .genre_test\bootstrap.log

Основной лог программы:
   .genre_test\logs\genre_test.log

В GUI также есть кнопка «Зависимости...», где отображается состояние Python, библиотек, CUDA/GPU, FFmpeg, HF auth и MAEST.

ЕСЛИ ЗАПУСК НЕ УДАЛСЯ
---------------------
1. Не удаляйте окно с ошибкой сразу — прочитайте строку [FAIL].
2. Откройте:
   .genre_test\bootstrap.log
3. Передайте этот файл вместе с описанием проблемы разработчику.

ВАЖНО
-----
- Не запускайте программу прямо из ZIP. Сначала полностью распакуйте архив.
- Не переносите только один CMD-файл отдельно от остальных файлов программы.
- Папка .venv создаётся рядом с программой и относится только к Genre_test.
- Аудиофайлы не отправляются в сторонний облачный сервис для жанрового анализа; основной анализ выполняется локально.
