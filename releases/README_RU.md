# Genre_test 0.3.6 Portable prerelease

Готовый дистрибутив для передачи другому пользователю:

- `Genre_test_0.3.6_portable.zip`
- контрольная сумма публикуется рядом в `SHA256SUMS.txt`
- распаковывать прямо в `C:\`
- итоговая папка: `C:\Genre_test_0.3.6_portable`
- запуск: `C:\Genre_test_0.3.6_portable\Genre_test_START.cmd`

Сборка основана на стабильном Genre_test 0.3.6 и не включает разработку 0.4.x.
